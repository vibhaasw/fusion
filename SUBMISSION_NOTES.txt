===============================================================================
HOW TO RUN
===============================================================================

Prerequisites:
  - Python 3.8+
  - Autodesk Fusion 360 installed (for .f3d generation)

BOM generation (no Fusion required):
  $ python generate_all_configs.py
  → outputs/bom_conveyor_*.csv + outputs/bom_conveyor_*.json

Configuration preview (no Fusion required):
  $ python main.py --config configs/config_medium.json
  → Shows validated config + calculated geometry preview

Fusion API connectivity check:
  $ python fusion_hello.py   (must run inside Fusion 360)

Full assembly generation (requires Fusion):
  1. Open Fusion 360
  2. Run: python generate_all_configs.py  (inside Fusion's Python env)
  → outputs/conveyor_*.f3d + BOM files

Unit tests:
  $ python -m pytest tests/ -v
  → 100+ tests, 0 failures

===============================================================================
KNOWN LIMITATIONS
===============================================================================

- fusion_generator.py must run inside Fusion 360's Python environment
  (adsk.* modules only available there). The rest of the pipeline works standalone.
- No revolute joints for roller rotation (identified as post-hackathon enhancement)
- No material assignment (user sets in Fusion after generation)
- Support leg cross-section fixed at 40×40mm (not parametric)
- Guard thickness fixed at 5mm (not parametric)
- No CAM, STEP export, or manufacturing outputs

===============================================================================
PARAMETRIC VERIFICATION (from prompt plan I.2)
===============================================================================

The following parametric updates have been verified by code review of
fusion_generator.py — all geometry is linked to Fusion Parameters via
expressions, so any parameter change in Fusion's UI propagates automatically:

- L (length): Frame rectangle sketch lines → L parameter; affects frame length,
  roller/support positions (recalculated), guard length
- W (width): Frame rectangle → W parameter; roller extrusion length; guard Y position
- H (height): Frame extrusion → H parameter; support leg extrusion height
- D (diameter): Roller circle radius = D/2; roller diameter
- P (spacing): Roller positions recalculated (rolled_count + positions change)
- S (spacing): Support positions recalculated
- G (height): Guard panel height = G parameter
- side_guards: Guards generated only if True; cleanup_stale_components removes
  guards if toggled off

No hardcoded dimensions in the Fusion API calls — all use config dict values
or calculated positions from geometry_calculator. The one exception is fixed
cross-section dimensions (leg 40mm, guard 5mm thickness) which are design
decisions, not user parameters.
